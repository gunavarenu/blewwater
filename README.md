# Blew Water

A premium futuristic vitamin water startup website designed with immersive storytelling, cinematic wellness aesthetics, and modern glassmorphism UI.

## Features

- Futuristic wellness-inspired design
- Responsive layout for all devices
- Glassmorphism UI effects
- Animated particles and gradients
- Founder showcase section
- Interactive storytelling experience
- Premium typography and spacing
- Smooth modern user experience

## Tech Stack

- HTML5
- CSS3
- JavaScript
